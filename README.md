# CoreField site

Landing page for CoreField at https://corefield.lyfescapes.net, hosted on GitHub Pages.

- `index.html`: the whole page. Paste your Formspree form address into `FORM_ENDPOINT` near the bottom.
- `media/`: the seven trade ad videos (web size), posters and the link-preview image.
- Link to a trade with `?trade=` (mold, inspect, build, plumb, electric, landscape, irrigate), e.g.
  `https://corefield.lyfescapes.net/?trade=inspect&utm_source=facebook&utm_campaign=inspect`
